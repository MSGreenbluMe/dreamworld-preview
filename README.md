# Dream World — kopie pro testování

Hratelná kopie, nic víc: stránka, moduly světa a three.js. Vlastní
projekt, jeho dokumenty a historie tu nejsou.

**Otevřít:** https://msgreenblume.github.io/dreamworld-preview/

- chůze **WASD**, běh **Shift**, rozhlížení **myší** (klikni do obrazu)
- **H** ukáže a skryje panel
- svět je zprvu prázdný a šedý. Ožívá tam, kudy někdo šel — jinde
  zůstává nic. To není porucha.
- stopy zůstávají v tomhle prohlížeči a nikam se neposílají

**Když je něco rozbité:** v panelu dole *Hlášení* → **zkopírovat
hlášení**, a pošli ten text tak, jak je. Když se stránka vůbec
nenačte, objeví se červené okno se stejným tlačítkem.

`?nosave` na konci adresy svět načte a nikdy do něj nezapíše.

Tahle kopie je dočasná a dá se kdykoli smazat.
